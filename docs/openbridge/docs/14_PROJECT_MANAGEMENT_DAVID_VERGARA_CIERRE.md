## 3. Contribuciones de coordinación para la entrega

### Comunicación y seguimiento

- Participar de los encuentros Daily en Discord y facilitar la puesta en común de avances y necesidades.
- Acompañar el seguimiento de tareas y dependencias, especialmente las interfaces entre Data, Backend, IA y Frontend.
- Organizar la información que el equipo aporta para que cada área sea representada sin confundir responsabilidades.

### Documentación y trazabilidad

- Consolidar un punto de consulta que conecte el problema del cliente, el producto, el repositorio técnico y las evidencias.
- Recibir documentos técnicos y transformarlos en **síntesis ejecutivas breves**, sin reemplazar la versión original.
- Mantener enlaces a los Pull Requests que respaldan contribuciones y explicar límites, métricas y funcionalidades pendientes.
- Incorporar el video real de navegación al README para facilitar la evaluación visual del proyecto.

### Preparación de la demo

- Ordenar un relato que explique **qué problema se busca resolver, qué muestra el producto, qué hace cada área y qué queda por validar**.
- Diferenciar resultados de pruebas documentadas, ejecución verificada por cada área y disponibilidad real en el entorno de demostración.
- Identificar aspectos para la revisión final con sus responsables, evitando anunciar como terminadas integraciones que todavía requieran comprobación.

6. **Repositorio oficial:** hecho: los documentos se integran al repositorio del equipo (13/11/2026).
